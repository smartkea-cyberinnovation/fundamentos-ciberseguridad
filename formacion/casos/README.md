# Casos prácticos de investigación y respuesta

Los casos complementan el itinerario de Fundamentos de informática y ciberseguridad. No cambian los identificadores de progreso, las 480 horas del catálogo ni la evaluación de una asignatura concreta.

| Caso | Competencias | Material |
|---|---|---|
| [C99-DFIR · Una shell con una llamada oculta](c99-forense/README.md) | Descubrimiento de webshells, uso de una shell legítima, preservación, análisis estático, cronología, correlación y respuesta | Guía de alumno, escenario sintético, herramienta offline, laboratorio Docker, soluciones y rúbrica |

Cada caso distingue evidencias de una muestra, datos sintéticos, interpretación y hechos no demostrados. Nunca se suben secretos, logs de una víctima o datos de estudiantes al repositorio público.
