# Guiones desarrollados sobre los laboratorios existentes

Estos ocho guiones concretan actividades del catálogo de 96 laboratorios; **no son ocho laboratorios adicionales**. Sus tiempos sustituyen el desarrollo genérico correspondiente. El docente puede reutilizar el material en otros módulos sin computarlo dos veces.

| Guion | Laboratorio principal | Duración | Resultado |
|---|---|---:|---|
| [R01 · Archivos y bytes](R01-archivos.md) | L05A | 3 h | Dataset comprendido y manifiesto contrastado |
| [R02 · Bash con errores](R02-bash.md) | L11A | 3 h | Script nativo explicado y probado |
| [R03 · Windows y objetos](R03-windows.md) | L16A | 3 h | Comparación CMD/BAT/PowerShell |
| [R04 · macOS y zsh](R04-macos.md) | L21A | 3 h | Portabilidad y verificación nativa |
| [R05 · Evidencias e indicadores](R05-evidencias.md) | L27B | 3 h | Cronología y coincidencias justificadas |
| [R06 · Servicio web local](R06-web.md) | L25A | 3 h | HTTP, logs, error y estado útil |
| [R07 · Cambio y reversión](R07-cambios.md) | L30C | 3 h | Antes/después y rollback demostrados |
| [R08 · IA y referencias](R08-ia.md) | L31B | 4 h | Validación estructural y crítica semántica |

Reparto ordinario: 20 minutos de preparación, 70 de práctica guiada, 40 de variante, 30 de evidencia y 20 de defensa/recuperación: 180 minutos. R08 utiliza 30/90/50/40/30: 240 minutos. Preparar datos y probar no significa haber impartido o validado los 96 laboratorios.

Entrega común: ficha de entorno, órdenes explicadas, resultados, caso negativo, límite y recuperación. Datos y actores ficticios. El repositorio es público: las soluciones y respuestas incluidas son referencias de aprendizaje, no material reservado. Los expedientes y exámenes no públicos necesitan un almacenamiento separado y permisos reales.
