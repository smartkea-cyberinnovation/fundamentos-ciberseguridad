# Lecciones desarrolladas y aprendizaje progresivo

Los módulos siguen siendo el mapa completo; estas ocho lecciones añaden explicaciones, ejemplos y preguntas de razonamiento. No reemplazan la práctica nativa ni constituyen por sí solas un manual completo de todas las especialidades.

| Lección | Foco | Módulos |
|---|---|---|
| [01 · Terminal y representación](01-terminal.md) | Bytes, intérprete, argumentos, rutas y evidencia | M02–M06 |
| [02 · Bash y automatización](02-bash.md) | Expansiones, errores, contratos y pruebas | M06, M11–M12 |
| [03 · Windows y PowerShell](03-windows.md) | CMD/BAT, objetos, permisos y estados | M13–M19 |
| [04 · macOS y zsh](04-macos.md) | Darwin, APFS, launchd y controles | M20–M23 |
| [05 · Operación de servicios](05-servicios.md) | Redes, remoto, web, TLS, Compose y Swarm | M10, M24–M26 |
| [06 · Evidencia e indicadores](06-evidencias.md) | Integridad, tiempo, coincidencias y conclusión | M27–M30 |
| [07 · IA supervisada](07-ia.md) | Datos no confiables, esquema, referencias y evaluación | M31 |
| [08 · Trabajo profesional](08-profesional.md) | Riesgo, producto, comunicación y portfolio | M04, M30, M32 |

Para cada tema: predecir, ejecutar sobre datos ficticios, comprobar de otra forma, explicar el resultado y registrar una limitación. La GUI se utiliza para localizar objetos y verificar estado; los comandos se evalúan por su efecto y su comprensión, no por memorizarlos.
